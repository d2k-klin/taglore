# @taglore/whats-new

What's New dialog and changelog page for release notes generated by [Taglore](https://github.com/d2k-klin/taglore). Two ways to use them:

## Any frontend: web component

No framework, no build step. Works in plain HTML, server templates (Django, Rails, Laravel, Thymeleaf, Razor), Vue, Angular and Svelte.

```html
<script type="module" src="/release-notes/taglore-whats-new.js"></script>
<taglore-whats-new src="/release-notes/latest.json" storage-key="myapp:whats-new"></taglore-whats-new>
```

The file comes from the Taglore action (`web-components: true` writes it to `output-dir`), or from jsDelivr: `https://cdn.jsdelivr.net/gh/d2k-klin/taglore@1/dist/whats-new.js`. With a bundler: `import "@taglore/whats-new/element";`

| Attribute | Default | |
|---|---|---|
| `src` | `/release-notes/latest.json` | Where the notes are served |
| `storage-key` | `taglore:whats-new:last-seen` | localStorage key for the acknowledged version |
| `show-on-first-visit` | off | Show the current announcement to brand-new visitors |
| `compact` | off | Summary and highlights only |
| `unstyled` | off | Don't inject the default CSS |
| `label-heading`, `label-highlights`, `label-improvements`, `label-fixes`, `label-breaking`, `label-close` | English | Text labels |

Methods `show()` and `dismiss()`; events `taglore:open` and `taglore:dismiss` (detail = the notes).

## React / Next.js

```bash
npm install https://github.com/d2k-klin/taglore/releases/latest/download/taglore-whats-new.tgz
```

```tsx
"use client";
import { WhatsNew } from "@taglore/whats-new";
import "@taglore/whats-new/styles.css";

export default function AppWhatsNew() {
  return <WhatsNew storageKey="myapp:whats-new" />;
}
```

| Prop | Default | |
|---|---|---|
| `url` | `/release-notes/latest.json` | Where the notes are served |
| `data` | | Pass notes directly instead of fetching |
| `storageKey` | `taglore:whats-new:last-seen` | localStorage key for the acknowledged version |
| `showOnFirstVisit` | `false` | Show the current announcement to brand-new visitors |
| `enabled` | `true` | Turn off, e.g. for logged-out users |
| `compact` | `false` | Summary and highlights only |
| `labels` | English | `heading`, `highlights`, `improvements`, `fixes`, `breaking`, `close` |
| `onDismiss` | | Callback after the user closes the dialog |
| `children` | | Render prop `({ notes, open, dismiss, show }) => ...` for your own UI |

`useWhatsNew(options)` exposes the same state as a hook. React is an optional peer dependency; the web component doesn't need it.

Both render every field as plain text, never as HTML. Style them through the `taglore-wn*` classes and `--taglore-wn-*` custom properties.

## Changelog page

Shows `history.json` (every release, newest first) with a search box.

```html
<taglore-changelog src="/release-notes/history.json"></taglore-changelog>
```

```tsx
import { Changelog } from "@taglore/whats-new";
<Changelog url="/release-notes/history.json" />;
```

| Attribute / prop | Default | |
|---|---|---|
| `src` / `url` | `/release-notes/history.json` | Where the history is served |
| `data` (React) | | Pass releases directly instead of fetching |
| `no-search` / `noSearch` | off | Hide the search box |
| `announced-only` / `announcedOnly` | off | Hide patch releases |
| `locale` | browser | Locale for dates |
| `label-*` / `labels` | English | `search`, `empty`, `highlights`, `improvements`, `fixes`, `breaking` |
